Port Meridian is an original open-world crime game that runs entirely in a desktop browser, fully offline with no server and no network calls. You explore a port city on foot and by car, weaving through traffic and crowds of pedestrians, and any parked or passing car can be stolen and driven. Causing trouble raises a 5-star wanted level, and the MPD (Meridian Police Department) answers in force — patrol cars pursue, roadblocks form, and the pressure only eases when you break line of sight and lie low. The story follows five jobs run for a fixer named Mara Voss, from a simple pickup at the docks to a final score across the harbor bridge. Combat, a HUD with a live minimap, a start screen, save games, and fully synthesized sound effects round out the package. Port Meridian is an original work with no connection to any commercial game — the city, characters, and missions were created for this project.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && node serve.ts
```

Then open http://localhost:8080 to play.
