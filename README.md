Port Meridian — an original open-world crime game: explore a port city on foot and by car, steal cars, outrun the MPD through a 5-star wanted system, and run five story jobs for fixer Mara Voss. Traffic, pedestrians, combat, minimap HUD, saves, synthesized sound. Offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && node serve.ts
```

Then open http://localhost:8080 to play.
